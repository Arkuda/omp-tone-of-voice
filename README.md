# Тон общения для omp

Расширение [omp](https://github.com/can1357/oh-my-pi) (`@oh-my-pi/pi-coding-agent`), добавляющее выбор тона общения главного агента: четыре роли или полное выключение. Выбранный тон сохраняется глобально (в профиле пользователя) и действует во всех новых беседах.

По умолчанию расширение **выключено**: оно не добавляет и не изменяет ни одного блока system prompt.

## Режимы

| Команда | Название | Манера |
|---|---|---|
| `/tone technical` | Технарь | Сухой технический специалист: без эмоций, эмодзи и оценок; вывод сначала |
| `/tone roast` | Унижающий | Постоянно недовольный специалист: на «ты», язвительные подколы и прямой грубый юмор, но с полезным ответом |
| `/tone gopnik` | Гопник | Короткие фразы, частый мат без запикивания, колорит бандитов из S.T.A.L.K.E.R. («шухер», «чики-брики и в дамки!», «за базар отвечать»); термины там, где они нужны |
| `/tone sweetheart` | Влюблённая девушка | От первого лица (женский род), восхищение пользователем, ласковые обращения и уменьшительные формы, много смайликов; фактическую точность сохраняет |
| `/tone off` | Выключено | Полное отключение: промпт не меняется вообще |

Тон влияет **только на главную сессию**. Сабагенты (инструмент `task`, eval `agent()`, клоны) получают исходный system prompt без стиля и возвращают нейтральные отчеты. Точность технических ответов, код, команды и идентификаторы не искажаются ни в одном режиме.

## Использование

```
/tone                # открыть меню выбора (в интерактивном режиме)
/tone off | technical | roast | gopnik | sweetheart
```

- Меню открывается на текущем режиме; `Esc` — отмена без изменений.
- Вне TUI пустая `/tone` показывает текущее состояние и подсказку.
- Выбор сохраняется в файл профиля и применяется к новым беседам после перезапуска или переключения сессии.
- Изменение тона действует со следующего запроса; уже отправленные сообщения не переписываются.

## Установка из этого репозитория

Требуется omp 18.18+ (Node ≥ 22.18 сборка не нужна — расширение исполняется нативно для omp).

```bash
git clone https://github.com/Arkuda/omp-tone-of-voice.git
cd omp-tone-of-voice
omp plugin link .
```

После этого запустите `omp` как обычно и выполните `/tone`. Расширение выключено до первого выбора.

Обновление: `git pull` в каталоге репозитория (junction/symlink подхватит изменения; при сомнении — повторно `omp plugin link .`).

Удаление: `omp plugin uninstall omp-tone-of-voice` (или `omp plugin unlink`, если ваша версия поддерживает) и удаление файла настроек, см. ниже.

## Как это работает

- При активном тоне расширение добавляет **один** блок `<tone-of-voice mode="…">` в конец массива system prompt на каждом подготовке запроса (`before_agent_start`), только для `ctx.agent.kind === "main"` и только для обычных пользовательских запросов (не `revive`).
- В выключенном состоянии обработчик возвращает `undefined` — без маркеров, compensating-инструкций и файлового IO.
- Обработчики привязываются и к сессиям сабагентов; там они завершаются до любого ввода-вывода, поэтому настройка не читается и не меняется из-под сабагента.

### Файл настроек

`<каталог профиля omp>/tone-of-voice.json`, формат:

```json
{"tone":"off"}
```

Допустимые значения `tone`: `off`, `technical`, `roast`, `gopnik`, `sweetheart`. Отсутствующий файл означает `off`. Битый JSON или неизвестное значение дают предупреждение при старте и выключают влияние, но не переписываются автоматически. Запись атомарная (временный файл + rename).

## Разработка / тесты

```bash
npm test   # node --test, внешних зависимостей нет
```

Тесты покрывают: персистентность через независимые экземпляры фабрики, переходы вкл/выкл без накопления блока, отмену и неизвестные аргументы, поврежденный файл, сбой записи (включая отключение при недоступной записи), изоляцию сабагент-сессий и headless-поведение команды.

## Ограничения

- Итоговая стилизация зависит от модели и провайдерских правил: расширение задает инструкции, но не обходит цензуру провайдера.
- Открытые параллельные процессы omp не синхронизируются по файловому watcher'у: сохраненный выбор применяется при старте/переключении беседы или собственном `/tone`.
